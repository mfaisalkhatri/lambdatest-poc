## :question: What is this Repository about?
- This repo contains example code to run a single test in parallel on two different browsers(Chrome and Firefox) on 
  [LambdaTest](https://www.lambdatest.com)
- [the-internet](https://the-internet.herokuapp.com) Website is used for testing Login scenarios using Form Authentication page.
- This repo uses Maven as build tool and TestNG testing framework to run the tests.
- To run the test from command line use the following command:
- `mvn clean install -Dusername=<lambdatest username> -Dtoken=<lambdatesttoken>`
